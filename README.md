# pdf-metadata

🔗 https://pdf-metadata.pages.dev/

## このツールについて

- PDFの「文書のプロパティ」（タイトル・作成者・件名・キーワード・作成アプリなど）を編集するツールです。
- 想定用途は主に2つです。
  - **個人情報の削除**：Wordなどで作成したPDFは、作成者欄に本名やアカウント名が自動で入っていることがあります。そうした項目を消す。
  - **検索されやすくする**：インターネットに公開するPDFにタイトル・キーワードを設定し、検索結果に出やすくする。
- **処理はすべてブラウザ内で完結し、PDFはサーバーに送信されません。**
- 公開は Cloudflare Pages を利用しています。

## 免責事項

- 本ツールは無保証で提供されます（現状有姿）。
- 処理はお使いのブラウザ内で完結しPDFは外部送信されませんが、ご利用環境に起因する情報漏えいについて作成者は責任を負いません。
- 本ツールの利用により生じたいかなる損害についても作成者は責任を負わず、本ツールは法的助言を提供するものではありません。
- 本ツールが書き換えるのはPDFの「文書のプロパティ」（Info辞書）のみです。ページ本文の文字・画像や、PDFによっては別途埋め込まれているXMPメタデータまでは削除されません。個人情報の削除が目的の場合は、保存後にPDFを開いて本文中に氏名等が残っていないか、あわせて確認してください。

## 仕組み（ブラウザ完結）

- `pdf-lib` でPDFを読み込み、タイトル・作成者・件名・キーワード・作成アプリ・PDF変換アプリの各項目を書き換えて保存し直します。
- 作成日・更新日は表示のみで編集はできません（保存すると更新日は自動的に現在日時になります）。
- パスワード保護（暗号化）されたPDFには対応していません。
- React / Next.js は使用していません（素のHTML＋バニラJSで実装しています）。

## ローカルで動かす

```bash
npm install          # wrangler を入れる
npm run dev          # http://localhost:8788 で確認
```
`python -m http.server -d public 8000` でも構いません。

## 公開（Cloudflare Pages）

```bash
npm run deploy       # wrangler pages deploy
```
本人・関係者限定にする場合は、Cloudflare Access（Google ログイン）を前段に設定してください。

## 運用上の注意

- 出力後は、別途PDFを開いて意図通りに書き換わっているか確認してください。
- 入力・出力PDFは `.gitignore` で除外済みです。**PIIを含むPDFはコミット・pushしないでください。**
